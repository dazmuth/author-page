Lock a book

Turns the book file (the epub) into an encrypted file that is safe to put on GitHub. Nothing is uploaded anywhere. Everything happens inside this browser tab.

1. Choose the full book (the .epub file)

2. Pick the code

A generated code is the safest choice. If you type your own, make it long and random (12 or more letters and numbers). Capital letters and dashes don’t matter when readers type it.

3. Lock it

Before you upload: save the code somewhere safe, like a password manager. It can’t be recovered. If you lose it, lock the book again with a new code. Upload only the .enc file to the website repository, never the original epub or PDF.
